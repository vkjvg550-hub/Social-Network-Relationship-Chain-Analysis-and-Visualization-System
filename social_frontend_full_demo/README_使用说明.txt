使用方法：
1. 解压 zip。
2. 双击 index_完整演示版.html。
3. 推荐用 Edge 或 Chrome 打开。
4. 不需要 Node.js，不需要联网，不需要服务器。

这个版本用于课堂演示：
- 能显示整个社交网络图。
- 能增加/删除用户。
- 能增加/删除好友关系、修改亲密度。
- 能查询关系链并高亮路径。
- 能根据阈值发现小团体。
- 能寻找信息最快初始投放点。
- 能导出当前网络为 social_output.txt。
- 能限时演示哈密顿通路和较快全用户传播路径。

注意：
哈密顿通路和“全部关系链”在图规模较大时是指数级问题。
前端为了不让浏览器卡死，做了数量和时间限制。
如果老师要求严格输出全部结果，建议由 C++ 程序输出，再让前端读取并展示。
